# Writing drafts

Put unfinished writings here as plain-text files.

The publish skill will preserve the draft's words and convert it into the portfolio's notes registry. It will not publish a draft unless the required metadata is available:

- title
- description
- date
- slug

You can provide metadata in the request or at the top of the draft, for example:

Title: My note title
Description: One-line description
Date: 18 Sep 2026
Slug: my-note-title

Everything after the metadata is treated as the draft body.
